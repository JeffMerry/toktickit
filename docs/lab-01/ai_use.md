## Selected Key Prompts

| Prompt Name | Actual Prompt Text | Reflection |
| --- | --- | --- |
| Planning lab 1 Structure | อ่านไฟล์ Lab1_Labsheet.pdf สรุปโครงสร้างของ lab1 โครงสร้างที่จำเป็นต้องมี สรุปออกมาเป็นทีละขั้นตอน |การใช้ AI ช่วยในการสรุปเนื้อหาโครงสร้างของ Lab1 ทำให้เรามองเห็นภาพรวมของ lab1 ได้ง่ายมากขึ้นอีกทั้งยังทำให้เร็วรู้ได้เร็วจากการที่มีขั้นตอนการทำไปทีละสเต็ป
| Project Setup | ช่วยสอนสร้างโครงสร้างของโปรเจคตาม Required Repository Structure สอนโดยละเอียดอธิบายทีละขั้นตอน | การเริ่มสร้างโปรเจคโดยให้ AI เป็นผู้สอนทีละขั้นตอนทำให้เราเห็นขั้นตอนการตั้งเเต่เริ่มสร้างไฟล์ เเละการเขียนคำสั่งsetup project เช่น npm create vite@latest . -- --template react-ts  npm install เเละการได้เรียนรู้การใช้คำสั่งติดตั้ง Packages(Bootstrap, Prisma, Vitest, Supertest) |
| Git Flow Management | ช่วยเเนะนำพื้นฐานการใช้คำสั่ง Git Branch ที่จำเป็นต่อlab1 เเละขั้นตอนการทำให้ได้ Git flow เหมือนตามlab1 | AI สอนคำสั่งที่จำเป็นต่อการทำงาน เช่น การใช้ Git init ที่จะเป็นตัวใช้เพื่อเริ่มเก็บประวัติโค้ดใหม่ในโฟลเดอร์ปัจจุบัน,Git checkout -b ..... เป็นการสร้าง branch ใหม่ถ้าไม่มี -b จะเป็นการกลับไปที่ branchนั้นๆ อีกทั้งยังบอกสิ่งที่จำเป็นคือเมื่อเราทำการ mergeเเต่ละครั้งเมื่อกลับมาที่ lab1 จำเป็นที่จะต้อง Git pull ก่อนเสมอเพราะการที่ใน Github โค้ดมันเปลี่ยนเเล้วเเต่ในคอมพิวเตอร์ของเราอาจจะยังเป็นโค้ดเวอร์ชั่นเก่าอยู่ |
| API Health Check| สอนการเขียน API Health Check ตามที่ Issue 2 ต้องการสอนโดยละเอียดเเละอธิบายเรื่อง Supertest | ได้เข้าใจมาตรฐานการทำ Health Check API ว่าควรคืนค่า Status 200 OK เมื่อการยิงapi นั้นไม่มีปํญหา พร้อมส่ง Payload JSON สั้นๆกลับไปเพื่อให้ Frontend ตรวจสอบสถานะการทำงานได้ ในส่วนของ supertest ได้รู้ว่ามันช่วยจำลอง HTTP request เข้าไปยัง express() instance ได้โดยตรง ทำให้การรัน Test ทำได้เร็วและไม่ชนกับ Port ของ Dev Server |
| Database and Seeding | ช่วยสอนสร้าง Prisma Model Category การใช้ Migration มาร่วมด้วยเเละการ Seed ข้อมูลตามที่ lab1 กำหนดมาสอนทีละขั้นตอนอธิบายโดยละเอียด | การสั่งให้ ai อธิบายเเละสอนไปทีละขั้นตอนทำให้เข้าใจจุดประสงค์ของเเต่ละ Dependencyเเละเห็นภาพรวมของการตั้งค่าการเชื่อมต่อระหว่าง Frontend,Backend,PostgreSql เเละเข้าใจว่าโฟล์ในโฟลเดอร์ prisma/migrations เป็นเหมือน Version Control ของโครงสร้างเพื่อให้เพื่อนที่ทำ PR สามารถดึงโค้ดไปใช้ได้ผ่านคำสั่ง npx prisma migrate dev ได้โดยไม่ต้องสร้าง database เองใหม่ทั้งหมด |
| Feature & UI React | ช่วยสอนการสร้าง API ในการดึง Categorites มาเเสดงผลในหน้าของ frontend พร้อมทั้งออกเเบบหน้า UI React ตามตัวอย่างของ lab1 เเละเขียน Tests พาทำทีละขั้นตอน | เข้าใจการบวนการส่งต่อข้อมูลตั้งเเต่การ Query ข้อมูลจาก PostgreSQL ผ่าน Prisma ใน Express API ไปถึงการ Fetch ข้อมูลมาอัปเดต State ใน React Component เพื่อเเสดงผลบน Bootstrap UI เเบบ Dynamic เข้าใจ Async UI States ทั้ง 3 สถานะ (Loading, Success, Error)  |
| Review and Documentation | ตรวจสอบตวามถูกต้องของโปรเจคว่าตรงตามความต้องการของ Lab1 หรือไหมพร้อมทั้งสรุปสิ่งที่ได้ทำลงไป | ใช้ AI เพื่อตรวจสอบความถูกต้องของโปรเจค โดย ai ได้อธิบายโครงสร้างโดยรวมของสิ่งที่ได้ทำลงไปเเละสอนคำสั่งในการทดสอบเช่น npm test ทั้งฝั่งของ client เเละ Server |
| Check Git Workflow | ตรวจสอบตวามถูกต้องของGit Graph ว่าตรงตามที่ lab1 ต้องการไหม | ใช้ AI เพื่อตรวจสอบความถูกต้องของGIt workflow โดยตรวจสอบเเละก็พบว่าทุก feature เกิดจากการเเตดออกมาของ lab1-staging โดยไม่มมีการยุ่งกับ main พอทำทั้งหมดเสร็จเเล้วก็จะนำ lab1-staging เข้าไปหา main ตรงตามที่ lab1 ต้องการ |
